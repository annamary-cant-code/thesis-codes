--------------------------------------------------------------------------------
HOW TO RUN THE PIPELINE
--------------------------------------------------------------------------------

The three phase files must be run IN ORDER. Each phase saves its outputs to
a .pkl file which the next phase loads at startup.

  STEP 1 — Run Phase1_GeoreferencedGrid.py
  STEP 2 — Run Phase2_Trajectory.py
  STEP 3 — Run Phase3_MonteCarlo.py

If you only change simulation parameters (GUESS, physical parameters) you
only need to re-run Phase 3. If you change the trajectory waypoints you need
to re-run Phase 2 and Phase 3. If you change the OSM file or grid resolution
you need to re-run all three phases.

Re-run schedule:

  Change                          Re-run
  ──────────────────────────────  ──────────────────────
  OSM file or bounding box        Phase 1 → 2 → 3
  Grid resolution (N_ROWS/N_COLS) Phase 1 → 2 → 3
  Waypoints in .xlsx file         Phase 2 → 3
  Sample spacing (SAMPLE_SPACING) Phase 2 → 3
  Physical parameters             Phase 3 only
  GUESS (Monte Carlo samples)     Phase 3 only
  Output grid resolution (N1/N2)  Phase 3 only
